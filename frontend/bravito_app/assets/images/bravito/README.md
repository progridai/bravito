# Assets Oficiais do Mascote Bravito

Esta pasta está preparada para receber os recortes oficiais do mascote Bravito, conforme o Manual de Identidade Visual.

Os assets oficiais (`bravito_em_pe.png`, `bravito_esferico.png`, `bravito_escudo.png`) devem ser exportados individualmente com fundo transparente a partir dos arquivos originais do manual de marca e colados aqui.

Não utilize as imagens inteiras do PDF como asset no aplicativo.
